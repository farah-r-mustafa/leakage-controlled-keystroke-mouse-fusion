# حزمة Keystroke–Mouse Stage 1 Pilot

## الغرض

تنفيذ فحص **Dataset Inventory, Integrity and Leakage Audit** فقط، من دون تعديل ملفات البيانات الأصلية، ومن دون معالجة كاملة أو تدريب نماذج.

## متطلبات التشغيل

- Windows 10.
- Python 3.12 أو أحدث.
- لا توجد مكتبات خارجية مطلوبة؛ يعتمد السكربت على مكتبات Python القياسية.

## ملف البيانات المعتمد

استخدم حصراً:

`Keystroke and Mouse Dynamics for UEBA Dataset.zip`

لا تستخدم `Keystroke Dynamics - Benchmark Data Set.zip` بديلاً عنه؛ فهو CMU StrongPassword Dataset مستقلة ولوحة مفاتيح فقط.

## التشغيل السريع

ضع ملف البيانات بجانب ملفات الحزمة، ثم شغّل:

`run_stage1_pilot.bat`

أو مرّر مسار الملف صراحةً:

`run_stage1_pilot.bat "<local_path>"`

## مخرجات السكربت

ينشئ مجلداً وملف ZIP باسم:

`keystroke_mouse_stage1_review`

ويتضمن الجرد، المخططات، عينات منزوعة التعريف، إحصاءات المستخدمين والجلسات، القيم المفقودة، التكرارات، الطوابع الزمنية، التسميات، المرشحات التعريفية، مخاطر التسرب، استراتيجية التقسيم، بدائل النوافذ، التحذيرات، سجل التنفيذ وملف SHA-256.

## ضمانات السلامة

- قراءة المصدر فقط.
- لا يفك ضغط البيانات إلى مجلد دائم.
- لا يكتب داخل ZIP الأصلي.
- لا ينفذ تدريباً أو تطبيعاً أو استخراج ميزات.
- يعالج الملفات صفاً بصف لتقليل استهلاك الذاكرة.
