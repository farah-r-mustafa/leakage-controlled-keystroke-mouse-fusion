# قرارات Stage 2B المجمدة

1. الاعتماد الحصري على 81 جلسة Core وتقسيم Stage 2A ذي البصمة:
   `e35422f0e48f96b6d1e4da99c9063379a6a488dd2bfa3e99d3e6e68857a7613d`.
2. عدم عبور أي نافذة حدود الجلسة الأصلية أو مقطع الخمول 60 ثانية.
3. Keyboard baseline: خمس أزواج صحيحة وخطوة زوجين. التسمية السابقة 50% اسمية، لكن التداخل الفعلي 60% لأن الحجم فردي، وتم توثيقه بدلاً من تغييره بعد التجميد.
4. Mouse baseline: عشر Mouse Strokes وخطوة خمسة، أي تداخل 50% فعلي.
5. Multimodal: نافذة 10 ثوانٍ وخطوة 5 ثوانٍ؛ تصدّر جميع `eligible_any` مع Masks، ويحدد `eligible_both` المسار الأساسي.
6. لا تصدّر الرموز الخام للضغطات ولا الحقول البيئية أو التعريفية ضمن الميزات الرقمية.
7. لا ينفذ Padding أو Scaling أو Imputation أو Feature Selection في هذه المرحلة.
8. ملفات JSONL التسلسلية مخصصة لاحقاً لـCNN وBiLSTM وCNN+BiLSTM، ويجب اشتقاق Padding/Truncation من Training فقط.
